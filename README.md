# Python Workbook 1 🚀

A comprehensive Python workbook containing hands-on exercises and solutions covering fundamental programming concepts, data structures, control flow, functions, object-oriented programming (OOP), and file handling.

---

### 🔹 Module 1: Python Basics & Variables
- **[Task 1.1](task1.1.py)**: Greeting with age calculation using user input & f-strings.
- **[Task 1.2](task1.2.py)**: Temperature converter from Celsius to Fahrenheit.
- **[Task 1.3](task1.3.py)**: Simple arithmetic calculator (+, -, ×, ÷).
- **[Task 1.4](task1.4.py)**: Total bill calculator based on price and quantity.
- **[Task 1.5](task1.5.py)**: Even or Odd number checker.
